# 康康熊桌宠 × FORCOME AI

面向 Windows x64 的 FORCOME AI CLI 桌面伴侣。安装一次即可获得 FORCOME AI、单一状态托盘、康康熊桌宠、本地日程提醒、便利贴和日历工具。

桌宠属于可选附加界面：隐藏、休眠或开启免打扰都不会停止 FORCOME AI CLI。

## 下载与安装

1. 前往 [Releases](../../releases) 下载最新的 `kangkangpet-setup-*.exe`。
2. 运行安装程序，可选择安装位置并创建桌面、开始菜单快捷方式。
3. 首次启动后，在控制面板的“设置”中登录 FORCOME AI，并按需启用开机启动。

应用数据保存在当前 Windows 用户目录。正常升级和卸载默认不会删除日程、便利贴与设置。

### 升级说明

- 当前公开版本为 `v1.0.14`，支持从早期 Windows x64 版本直接覆盖升级，包括 `v1.0.7`。
- 应用启动时会检查 GitHub Releases；也可以在控制面板的“设置”中手动检查。
- 发现新版本后会先询问是否下载，下载完成后自动退出、安装并重新启动。
- 如果启动时网络暂时不可用，更新检查会在后台自动重试；当前版本、日程、便利贴、设置和钉钉授权凭据会保留。
- 更新失败时可先确认网络能访问 GitHub，再重新点击“检查更新”；详细错误会写入本机日志目录。

如果电脑曾单独安装过 FORCOME AI CLI，点击“安装”进入进度页后，安装器会移除旧版 C 盘目录、连接器/托盘进程、计划任务、Run 自启项、PATH、快捷方式、卸载注册项以及 npm 全局版，确认无冲突后才继续安装。旧版清理不会删除 `.lobehub` 中的钉钉登录凭据，也不会影响 FORCOME AI PWA 或 Forcome Cloud。

## 核心功能

### FORCOME AI CLI

- 内置 FORCOME AI CLI，无需再单独安装。
- 使用一个 FORCOME 图标托盘显示登录、连接和离线状态。
- 网络中断或连接器异常退出后按递增间隔自动重连。
- 单击托盘显示或隐藏康康熊，双击托盘打开控制面板。
- 托盘菜单负责登录、重连、暂停连接器等 CLI 管理。
- 设置页可检查 CLI 自身更新，并提供运行日志入口；更新安装仍由 CLI 自己执行，避免桌宠运行时替换文件。
- 首次使用按服务端要求在浏览器完成一次钉钉授权；授权凭据存在后，控制面板入口会自动启动连接器，不再要求输入账号密码。托盘中的“重新登录 / 切换账号”仍可强制重新走授权流程。

### 康康熊桌宠

- 单击熊进行互动，双击熊打开 FORCOME AI。
- 双击熊通过已安装 PWA 的所属浏览器和应用标识唤起；普通浏览器中的同名网页不会被误复用，找不到 PWA 时才回退到系统默认浏览器。
- 熊本体右键菜单只保留常用桌宠入口，与系统托盘职责分开。
- 免打扰模式会停止闲置动作、视频、互动按钮和普通气泡，但仍允许双击打开 FORCOME AI，并正常显示日程提醒气泡和系统通知。
- 低资源模式减少视频预加载和闲置动作；锁屏、休眠或隐藏后会回收桌宠资源，不影响 CLI。

### 员工守则与工作模式

- 工作模式默认开启，桌宠旁的互动入口会切换为员工守则小贴士。
- 员工守则内容由主进程从 Dify 知识库同步，缓存或内置默认内容会在网络暂时不可用时继续生效。
- 工作日会随机展示轻量小贴士，也可以手动抽取、继续阅读上一条或查看最近的小贴士。
- 工作模式下主动点击“随机来一条小贴士”或“继续阅读上一条”会立即切换当前员工守则气泡，不会无限堆积气泡队列；普通日程提醒仍按原有队列展示。
- 休息模式恢复普通桌宠互动，不影响已安排的提醒。
- Dify API Key 只从运行环境读取，不写入项目文件、配置文件或渲染页面。

### 日历与提醒

- 支持年、月、周、日视图，以及拖动日程调整日期。
- 支持一次、每天、每周、自定义星期和间隔提醒。
- 支持桌宠气泡、Windows 系统通知、提前提醒和需要确认的强提醒。
- 支持 CSV、XLSX、JSON 和自然语言文本导入，以及批量启用、停用和删除。
- 默认显示中国法定节假日：红色“休”为放假，蓝色“班”为调休补班。
- 节假日每日从中国政府网国务院办公厅通知同步，离线时使用官方通知缓存。
- 可选显示美国联邦节假日：从美国人事管理局（OPM）同步，离线时使用本机缓存；与中国节假日分开标注。
- 中国和美国节假日设置位于同一个“法定节假日”卡片中，通过 🇨🇳 / 🇺🇸 标签区分日历来源。

### 工作工具

- 工具页提供世界时钟、日期计算、纪念日管理和常用单位换算。
- 支持查询人民币、美元、欧元、日元、港币、英镑、加拿大元及其他常见货币之间的最新参考汇率，并显示数据日期与读取时间。
- 汇率数据仅用于参考；网络不可用时不会伪造结果，重复查询会优先使用短期缓存。

### 便利贴

- 支持普通备忘和任务清单两种模式。
- 任务清单支持优先级、子任务和每日自动重置。
- 标题位于正文编辑区并加粗，与普通正文通过细线分隔。
- 顶部标题栏的大面积空白区域可直接拖动便利贴。
- 支持置顶、显示全部和隐藏全部。

## 菜单分工

熊本体右键菜单用于快速操作：

- 查看 FORCOME AI 状态、打开 FORCOME AI；
- 隐藏桌宠；
- 快速新建提醒、新建便利贴；
- 显示或隐藏全部便利贴；
- 打开控制面板；
- 开启或退出免打扰模式。

系统托盘菜单用于完整的 FORCOME AI CLI 管理，并提供桌宠与提醒功能入口。

## 隐私与资源

- 日程、提醒、便利贴和桌宠配置仅保存在本机当前用户目录。
- 应用不会上传这些本地内容。
- 联网行为仅包括 FORCOME AI 服务、GitHub 更新检查、中国政府网节假日同步和可选的 OPM 美国联邦节假日同步。
- 更新安装会先退出当前程序和内置 CLI 连接器，安装完成后自动重新启动。
- 桌宠窗口可以独立销毁；FORCOME AI CLI 与唯一托盘继续在后台运行。
