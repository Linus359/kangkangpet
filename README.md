# 康康熊桌宠

Windows 桌面宠物与本地提醒工具。日程、提醒和素材仅保存在当前 Windows 用户的本地配置中。

## 快速使用

1. 在 [Releases](../../releases) 下载并运行最新安装包。
2. 右键桌宠或系统托盘图标，打开控制面板。
3. 在“日历”中滚动浏览月份、拖动日程调整日期；左侧小日历的小点表示当天有日程。
4. 在“提醒管理”中创建、筛选和批量管理提醒；勾选“强提醒”后，提醒需点击确定才会关闭。
5. 单击桌宠触发互动，拖动调整桌面位置，双击打开 FORCOME AI。

详细开发、构建与发布说明仅保留在本地 `LOCAL_DEVELOPMENT.md`。
