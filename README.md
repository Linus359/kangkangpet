# 康康熊桌面宠物

康康熊是一个 Windows 桌面宠物和本地提醒工具。应用离线运行，提醒和素材保存在当前 Windows 用户的本地配置中。

## 使用

1. 从 Releases 下载并运行安装包。
2. 首次启动后，康康熊会显示在桌面上；右键桌宠或系统托盘图标可打开控制面板。
3. 在“日历”和“提醒管理”中创建、编辑或管理本地提醒。
4. 单击康康熊触发互动，拖动可调整位置；双击可打开 FORCOME AI。

## 开发

```powershell
npm install
npm start
```
